Compile `main.tex` using XeLaTeX, twice for references.

Sections 1–5 contain the mission description, preliminary design decisions and principal predicted performance. Appendix A and B retain original operational and payload detail; Appendices C–F remain placeholders for later validated technical studies; Appendices G–J preserve original source text, tables and figures transferred out of the main body. The writing deliberately retains terms and numerical statements from the user-provided draft. Differing assumptions are identified instead of silently resolved. This is **not** a validated final engineering baseline.
